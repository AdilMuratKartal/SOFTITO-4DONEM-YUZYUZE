📱 Flutter Cross-Platform Desteği

Bu model saf glTF 2.0 (.glb) standardında üretilmiştir. iOS, Android, macOS, Windows ve Web üzerinde model_viewer_plus veya o3d paketleriyle doğrudan çalışır.

Flutter (iOS, Android, macOS, Windows) Entegrasyonu

1. pubspec.yaml dosyanıza paketi ekleyin:

dependencies: flutter: sdk: flutter model_viewer_plus: ^1.7.0 # iOS, Android, macOS, Windows, Web uyumlu flutter: assets: - assets/models/yumurta_maskot.glb

2. Flutter Widget Kullanımı:

import 'package:flutter/material.dart'; import 'package:model_viewer_plus/model_viewer_plus.dart'; class YumurtaMaskotWidget extends StatelessWidget { final String emotion; // 'mutlu', 'uzgun', 'kizgin', 'depresif' vb. const YumurtaMaskotWidget({Key? key, this.emotion = 'mutlu'}) : super(key: key); @override Widget build(BuildContext context) { return SizedBox( height: 380, width: double.infinity, child: ModelViewer( backgroundColor: const Color(0xFFF7E5DB), src: 'assets/models/yumurta_maskot.glb', alt: 'Yumurta Maskot 3D', autoRotate: true, autoRotateDelay: 1000, cameraControls: true, shadowIntensity: 0.6, exposure: 1.0, ), ); } }

İpucu: .glb dosyasını üstteki ".GLB Olarak İndir" düğmesine basarak bilgisayarınıza kaydedebilir ve Flutter projenizin assets/models/ klasörüne ekleyebilirsiniz.
